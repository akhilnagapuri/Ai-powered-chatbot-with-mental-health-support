# Ai-powered-chatbot-with-mental-health-support
Developing a Ai-Powered chatbot with sentiment analysis for mental health support

this system detects the users emotional state from text input and provides supportive responses or guidance.it aims to provide accessible and stigma-free mental health assistance.
